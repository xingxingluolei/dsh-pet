# Desktop pet asset credits

This project includes nine transparent GIF animations and local icons extracted from the blue maid asset set in LLMPET. The selected GIF files are `idle.gif`, `sleeping.gif`, `thinking.gif`, `working.gif`, `juggling.gif`, `sweeping.gif`, `waiting.gif`, `error.gif`, and `happy.gif`.

Character artwork and local refinements used image generation/editing tools. Original motion references came from **抖音 @月薪喵**. Transparent conversion, timing and transformation provenance are retained in `manifest.json`; source filenames there describe the upstream asset history.

The software MIT license does not grant additional rights to the original reference material. Character transformation or repository distribution does not expand those rights. The character name does not imply affiliation, endorsement or cooperation with DeepSeek.

The filenames map to application task states; they do not necessarily describe the literal action drawn in each animation. Only the nine animations required by this standalone application are included.
